01Agent systems

Recoverable AI workspaces

I built conversation lineage and account-scoped context around interrupted streams and partial output. Single-flight readback reconciles saved state; deadlines and late-result fencing keep late responses from overwriting newer work.

02Interface engineering

Embedded mini-app interfaces

I built React/TypeScript host-SDK handoffs and session hydration for embedded flows: challenge, search and leaderboard UI, media grids, mobile navigation and failure states. The work connects host context to the interface users actually navigate.

Implemented source

03API reliability

Social/API recovery

A retry after a lost response can duplicate a post or message. I used stable operation IDs with payload/actor binding to preserve the original result after a simulated lost SQL response.

Fixture regressions

Real database effects have not been established.

04Systems research

Experimental compiler + runtime

I implemented parser, type/effect analysis, HIR/MIR, CVM and Wasm paths. Verifier-before-execution, VM step/frame limits and capability-guarded Wasm make execution boundaries explicit.

Experimental · historical bounded tests

Full self-hosting and production guarantees are not established.

Interactive SVG systems explorer

Experiments that can survive contact with reality.

I treat research claims as engineering claims: define the hypothesis, freeze the metric, isolate held-out evaluation, record negative evidence, and keep proposal authority separate from acceptance authority.
